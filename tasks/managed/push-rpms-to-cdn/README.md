# push-rpms-to-cdn

Tekton task to push RPMs from Konflux builds to CDN via rhsm-pulp using pubtools-pulp-push.

## Overview

This task is designed to be integrated into larger release pipelines that handle RHEL RPM delivery workflows.
It consumes CDN metadata files generated by upstream tasks and performs the actual push to CDN.

**Workflow:**
1. Reads advisory metadata from expected file locations (generated by upstream metadata tasks)
2. Calls pubtools-pulp-push with konflux: source to query Konflux Hosted Pulp for RPMs by SHA256
3. Creates temporary repository in Hosted Pulp and syncs content
4. Syncs from temp repo to RHSM Pulp via YUM feed
5. Associates RPMs to destination repos and publishes
6. pubtools-exodus hook creates and commits exodus-gw publish to CDN

## Prerequisites

### 1. Pulp Access

This task requires access to Konflux Hosted Pulp for retrieving RPM artifacts. The namespace must have the appropriate `pulp-access` secret configured.

### 2. CDN Metadata Files

This task requires CDN metadata files to be generated by an upstream task. The metadata generation is out of scope for this task.

**Required file structure** (mandated by pushsource konflux backend):
```
$(dataDir)/advisories/${ADVISORY_ID}/
├── advisory_cdn_metadata.json
└── advisory_cdn_filelist.json
```

Where `${ADVISORY_ID}` comes from `data.json` at path `.pushOptions.advisory_id`.

The metadata files should contain:
- `advisory_cdn_metadata.json`: Advisory metadata (equivalent to Errata's `get_advisory_cdn_metadata` API)
- `advisory_cdn_filelist.json`: File list metadata (equivalent to Errata's `get_advisory_cdn_file_list` API)

## Parameters

| Name                    | Description                                                                                                                          | Optional | Default value        |
|-------------------------|--------------------------------------------------------------------------------------------------------------------------------------|----------|----------------------|
| snapshotPath            | Path to the JSON file of the mapped Snapshot spec in the data workspace                                                              | No       | -                    |
| dataPath                | Path to the JSON file of the merged data to use in the data workspace                                                                | No       | -                    |
| konfluxPulpDomain       | The Konflux Pulp domain to use for retrieving RPM artifacts                                                                          | No       | -                    |
| pushSecret              | The secret containing authentication credentials for rhsm-pulp and exodus-gw                                                         | No       | -                    |
| pipelineImage           | The container image with pubtools-pulp-push and dependencies                                                                         | Yes      | quay.io/konflux-ci/release-service-utils:latest |
| ociStorage              | The OCI repository where the Trusted Artifacts are stored                                                                            | Yes      | empty                |
| sourceDataArtifact      | Location of trusted artifacts to be used to populate data directory                                                                  | Yes      | ""                   |
| ociArtifactExpiresAfter | Expiration date for the trusted artifacts created in the OCI repository. An empty string means the artifacts do not expire           | Yes      | 1d                   |
| trustedArtifactsDebug   | Flag to enable debug logging in trusted artifacts. Set to a non-empty string to enable                                               | Yes      | ""                   |
| orasOptions             | oras options to pass to Trusted Artifacts calls                                                                                      | Yes      | ""                   |
| dataDir                 | The location where data will be stored                                                                                               | Yes      | /var/workdir/release |
| taskGitUrl              | The url to the git repo where the release-service-catalog tasks and stepactions to be used are stored                                | No       | -                    |
| taskGitRevision         | The revision in the taskGitUrl repo to be used                                                                                       | No       | -                    |
| caTrustConfigMapName    | The name of the ConfigMap to read CA bundle data from                                                                                | Yes      | trusted-ca           |
| caTrustConfigMapKey     | The name of the key in the ConfigMap that contains the CA bundle data                                                                | Yes      | ca-bundle.crt        |
| dryRun                  | Enable dry-run mode - metadata will be generated and validated, but no actual push will occur                                        | Yes      | false                |

## Data Configuration

The task expects the following configuration in the `data.json` file (passed via ReleasePlanAdmission):

```json
{
  "pushOptions": {
    "advisory_id": "RHBA-2026:12345",
    "pulp_url": "https://<rhsm-pulp-url>",
    "exodus_gw_url": "https://<exodus-gateway-url>",
    "cdn_env": "stage"
  }
}
```
